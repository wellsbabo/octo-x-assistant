집·회사 설정 공유

집·회사 Chrome에서 같은 Google 계정으로 로그인하고, Chrome 설정 → 나와 Google의 관계 → 동기화에서 ‘확장 프로그램’을 켜세요. 양쪽에 고정 ID 버전을 설치해야 합니다. 댓글 지침·키워드·제외 계정만 공유하며 API 키·X 로그인·글·통계는 각 기기에 남습니다.

설정 저장과 계정 제외 시 자동 반영됩니다. Chrome 저장소 반영과 실제 기기 간 전송은 다르며 전송에 시간이 걸릴 수 있습니다. 동시에 수정하면 나중에 도착한 설정으로 바뀔 수 있습니다.

기존 버전에서 한 번만 · 기록 옮기기

먼저 기존 확장에 이전용 버전을 덮어쓰고 ‘기록 백업’을 누릅니다. 고정 ID 버전을 새 폴더에 설치하고, 아직 사용 기록이 없는 상태에서 복원하세요. API 키와 X 토큰은 백업에 포함되지 않습니다. 새 Callback URL을 X 앱에 추가하고 X를 다시 연결하세요. 회사에서는 집의 기록을 복원하지 않아도 공유 설정만 자동으로 받습니다.

전체 로컬 기록 이전용입니다. 다른 기기의 통계와 병합하는 기능은 아닙니다. 복원은 기존 기록이 없는 새 설치에서만 가능합니다.

01

X 계정 연결

타임라인과 한국어 키워드 검색에 사용합니다.

연결 안 됨

Public client + PKCE 방식입니다. Client Secret은 사용하지 않습니다.

연결 진단은 기존 토큰으로 내 계정과 @JungkwanDean 조회를 비교합니다. 사용자 정보 최대 2건의 읽기 비용이 발생할 수 있습니다(기본 단가 기준 최대 $0.02). 재로그인이나 게시물 수집은 하지 않습니다.

처음이라면 · X 개발자 앱이 뭔가요?
  1. X 개발자 사이트에서 계정을 만들고 API 이용·결제 설정을 완료합니다.
  2. 프로젝트/앱을 만들고 User authentication settings에서 OAuth 2.0을 활성화합니다.
  3. 앱 유형은 Native App 또는 Single Page App 등 public client를 선택합니다. Client Secret이 필수인 Web App/Bot 유형은 이 확장에서 지원하지 않습니다.
  4. 권한은 읽기 전용으로 설정하고, 이 화면의 Callback URL을 정확히 등록합니다. Website URL이 필요하면 본인의 공개 X 프로필 URL을 입력할 수 있는지 해당 콘솔의 요구 조건을 확인하세요.
  5. OAuth 2.0 Client ID를 복사해 위에 넣고 ‘저장하고 X 연결’을 누릅니다. API Key나 Bearer Token과 다른 값입니다.
  6. X 로그인 화면에서 tweet.read users.read offline.access 권한을 승인합니다. 연결 계정이 @JungkwanDean인지 확인합니다.

화면 명칭과 API 접근 조건은 변경될 수 있습니다. 주소 불일치 오류는 등록된 Callback URL과 위 주소를 비교하세요. 확장 프로그램을 다른 폴더/기기에 재설치하면 주소가 바뀔 수 있습니다.

02

댓글 AI 연결

현재 보고 있는 글의 요약과 댓글만 생성합니다.

OpenAI API 키 관리에서 기존 잔액이 있는 조직·프로젝트의 키를 발급하거나 사용하세요. Responses 쓰기 권한과 선택한 모델 이용 권한이 필요합니다. ChatGPT 구독과 API 결제는 별도입니다.

xAI 콘솔에서 발급한 키를 사용합니다. OpenAI 키와 별도로 저장합니다.

이미 만든 댓글은 유지됩니다. 새 지침을 적용하려면 사이드바에서 다시 생성을 누르세요.

03

찾고 싶은 대화

인증 계정의 한국어 원글 중 키워드가 포함된 글만 모읍니다.

‘-’ 없이 단어만 입력하세요. has:cashtags를 넣으면 $NVDA처럼 티커가 붙은 글을 뺍니다. 타임라인에서 읽은 글에도 같은 기준을 적용합니다.

이 앱에서만 제외합니다. X 차단 목록과 자동 동기화하지 않습니다. API가 차단 상태·비공개·열람 제한 정보를 반환하면 해당 글도 제외합니다. 표시되지 않는 제한은 자동 판별하지 못할 수 있습니다.

‘더 가져오기’를 누를 때만 타임라인 1페이지와 검색 1페이지를 읽습니다. 필터에서 제외된 글도 읽기 비용이 발생합니다. 키워드가 많으면 검색 묶음을 순환합니다. 인증 계정만 수집합니다(파란딱지·기업·정부 인증 포함). 인증 정보가 없으면 제외합니다. 리포스트·내 글·답글(스레드의 후속 답글 포함)은 제외합니다. 인용 게시물은 포함합니다. 페이지를 다 읽으면 다음 수집은 최신부터 다시 시작합니다.

04

비용 계산 기준

실제 청구서가 아닌, 이 확장에서 발생한 요청의 추정치입니다.

게시물·단독 사용자 조회 ID는 UTC 날짜 내에서 중복을 제거해 추산합니다. 게시물 응답에 포함된 작성자 부가 정보는 독립 사용자 조회로 가산하지 않습니다. ‘오늘’과 월간 통계는 한국시간으로 묶습니다. AI 캐시 사용량이 응답에 있으면 별도 단가를 적용합니다. 단가 변경은 이후 요청에만 적용합니다. 다른 앱의 사용량, 서비스의 중복 제거 예외, 응답을 받지 못한 요청, 세금·환율 등은 반영하지 못합니다. X 콘솔의 실제 금액과 차이가 있을 수 있습니다.

어디에 저장되고, 어디로 전송되나요?

이 기기의 확장 저장소: 설정·API Key·액세스/갱신 토큰·후보 글·수정한 댓글·처리 이력·통계. 댓글 지침·키워드·제외 계정만 Chrome 동기화 저장소에 보관합니다. 별도 서버는 사용하지 않습니다. 로컬 저장소는 비밀 금고처럼 암호화되는 공간은 아닙니다.

X로 전송: 로그인 정보와 인증 코드/토큰, 타임라인·검색 요청 및 키워드. 선택한 AI 제공사(OpenAI 또는 xAI)로 전송: 해당 제공사의 API Key, 현재 글의 작성자 이름과 본문, 댓글 작성 지침. 선택하지 않은 제공사에는 전송하지 않습니다. Responses API에는 store: false를 지정합니다. 각 서비스의 자체 데이터 처리 정책도 적용됩니다.

연결 해제는 이 기기의 X 토큰을 삭제합니다. 원격 권한 철회는 X의 ‘설정 → 보안 및 계정 접근 권한 → 앱 및 세션 → 연결된 앱’에서 처리하세요. 확장 삭제 시 로컬 기록도 삭제됩니다.

설정은 이 기기에만 저장됩니다.
