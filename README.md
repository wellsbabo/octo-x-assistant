# 옥토 · X 대화 도우미 v1.3.0

X API로 한국어 글을 모으고, GPT가 만든 요약·댓글을 Chrome 사이드바에서 검토·수정·복사하는 개인용 확장입니다. Manifest V3 / Side Panel / Vanilla JavaScript이며 빌드나 별도 서버가 필요 없습니다.

**기본 제공사: OpenAI / 기본 모델: `gpt-6-luna` / 추론: `none`.** 설정에서 xAI·Grok도 선택할 수 있습니다. 실제 게시와 팔로우는 X에서 직접 진행합니다.

## v1.2.0 화면·원문·댓글 지침·제외 목록

- 사이드바와 설정을 검정·회색 중심으로 바꾸고 로고·강조색·장식 크기를 줄였습니다.
- **원문 열기**는 새 탭을 만들지 않고 현재 창의 활성 탭을 해당 글로 이동합니다. Chrome Tabs API로 탭 ID만 확인하므로 새 권한은 추가하지 않았습니다.
- 설정 → 댓글 AI 연결 → **댓글 작성 지침**을 수정하고 저장하면 다음 AI 생성부터 적용됩니다. 기본 지침은 ‘와우’ 같은 상투적인 감탄·과장된 칭찬을 피하는 담백한 1~2문장입니다. 기본 지침 복원 버튼도 있습니다. 요약·JSON 출력 형식은 확장이 별도로 유지합니다. 기존 초안은 다시 생성하기 전까지 바뀌지 않습니다.
- **이 글 제외**는 해당 게시물 ID, **이 계정 제외**는 가능한 경우 작성자 ID를 이 Chrome에 저장합니다. 같은 계정의 대기 글도 제외하고 초안은 백업합니다. 제외는 본 글/게시 횟수에 더하지 않고 자동 AI 호출도 하지 않습니다. 다음 글에서 필요하면 댓글 만들기를 누르세요.
- 설정의 **수집 제외 계정**에는 `@아이디` 또는 `id:숫자`를 한 줄에 하나씩 입력합니다. 계정 ID로 제외하면 이름이 바뀌어도 적용됩니다. 목록에서 지우고 저장하면 이후 새 수집부터 다시 허용합니다. X의 차단/해제 상태를 변경하거나 차단 목록 전체를 동기화하는 기능은 아닙니다.
- 수집 응답에서 작성자 `protected`, `withheld`, `connection_status: blocking`, 게시물 `withheld`, `scopes.followers` 등 제한 표시를 확인하면 후보에서 제외합니다. 비공개 계정은 팔로우 여부와 관계없이 보수적으로 제외합니다. 같은 응답에 새로 나타난 작성자 제한은 기존 대기 글에도 반영합니다.
- API가 해당 정보를 생략하거나 수집 후 상태가 바뀐 경우, X 웹 화면의 모든 열람 제한을 확정할 수 없습니다. 첨부 화면 같은 현상을 100% 방지한다고 보장하지 않습니다. 열람 권한 우회나 웹 페이지 접근 검사는 하지 않습니다. 정보가 누락된 글은 직접 **이 글 제외/이 계정 제외**를 사용하세요. `reply_settings`는 답글 작성 권한이며 열람 제한과 혼동해 차단하지 않습니다.
- 필터는 수집 응답 안에서 동작합니다. 별도 유료 계정/게시물 확인 요청은 추가하지 않지만, 응답에 포함됐다가 제외된 글의 X 읽기 비용은 발생할 수 있습니다.

## v1.3.0 Chrome 설정 공유 / 인증 계정 전용

댓글 지침·키워드·제외 계정만 Chrome `storage.sync`에 저장합니다. API 키, OAuth 토큰, X Client ID, 모델/단가, 글·초안·처리 이력·통계·비용은 동기화하지 않습니다. 집과 회사에서 같은 Google 계정의 Chrome 프로필로 로그인하고 동기화의 ‘확장 프로그램’을 켜야 합니다. 회사 정책이나 동기화 비활성화 상태는 이 앱에서 확인할 수 없습니다.

`manifest.json`의 공개 `key`로 설치 폴더·컴퓨터가 달라도 확장 ID를 같게 유지합니다. 이 키는 API Key나 비밀키가 아닙니다. 이전 설치에는 고정 키가 없으므로 아래 순서로 한 번 전환해야 합니다. 고정 ID 버전으로 옮긴 이후에는 같은 폴더를 덮어쓰고 새로고침하면 됩니다.

### 기존 사용자 전환 · 집에서 한 번

1. **이전용 ZIP**(`octo-x-assistant-migration-v1.3.0.zip`)을 풀고 기존 설치 폴더에 덮어씁니다. 이전용에는 manifest key가 없으므로 폴더를 이동하지 마세요. `chrome://extensions`에서 기존 확장을 새로고침합니다.
2. 기존 확장 설정 → ‘집·회사 설정 공유’ → ‘기존 버전에서 한 번만’ → **기록 백업 내려받기**를 누릅니다. 기록·초안·설정이 JSON에 저장됩니다. API 키와 X 토큰은 포함하지 않습니다.
3. **고정 ID ZIP**(`octo-x-assistant-v1.3.0.zip`)을 다른 폴더 `octo-x-assistant-sync`에 풀고 Chrome 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다. 기존 확장은 백업이 끝날 때까지 제거하지 마세요.
4. 새 확장 설정에서 **빈 저장소에 기록 복원**으로 방금 받은 JSON을 선택합니다. 새 저장소가 비어 있을 때만 복원할 수 있고, 다른 기기 통계를 병합하는 기능은 아닙니다. 인증 정보가 없던 기존 대기 글은 백업으로 보관됩니다.
5. 새 확장의 Callback URL을 X 개발자 앱에 추가하고 X를 다시 연결합니다. API 키도 새 확장에 입력하고 저장합니다. Client ID는 백업에서 복원됩니다. 키 원문을 파일이나 채팅으로 전달하지 마세요.
6. Chrome 설정 → 나와 Google의 관계 → 동기화에서 ‘확장 프로그램’을 켭니다. 새 확장 설정에서 Chrome 동기화 저장소 반영 상태를 확인하세요. 옛 확장은 꺼두고 새 확장을 사용합니다.

### 회사에서 설치

1. 집과 같은 Google 계정의 Chrome 프로필에서 동기화와 ‘확장 프로그램’을 켭니다.
2. 같은 **고정 ID ZIP**을 설치합니다. 확장 파일 자체가 자동 설치된다고 가정하지 않고 각 컴퓨터에 한 번 로드합니다. 이전용 ZIP을 회사에 설치하지 마세요.
3. 새 확장의 ID가 집과 같은지 설정 화면에서 확인하고 **공유 설정 받기**를 누릅니다. Chrome 전송에 시간이 걸릴 수 있습니다. 기본값을 먼저 저장하지 말고 집에서 설정한 지침·키워드·제외 목록이 들어왔는지 확인하세요.
4. 회사 기기에서도 X Client ID·API 키를 직접 입력하고 X를 연결합니다. Callback URL은 고정 ID 버전끼리는 같습니다. 집의 기록 JSON을 회사에 복원할 필요는 없습니다.

설정 저장·이 계정 제외 버튼은 자동으로 공유 저장소에도 반영합니다. ‘이 글 제외’의 개별 게시물 ID와 통계는 공유하지 않습니다. 오류가 나면 로컬 저장은 유지하고 오류를 표시하며 미전송 상태를 보존합니다. 다음 시작 때 재시도하거나 ‘이 기기 설정 보내기’를 누를 수 있습니다. 미전송 로컬 설정이 있으면 과거 원격 설정으로 덮어쓰지 않습니다.

이 앱의 ‘Chrome 동기화 저장소 반영’은 Chrome 저장소 쓰기 성공이며 Google 서버 업로드나 다른 기기 도착 확인이 아닙니다. 동시에 수정하면 나중에 도착한 스냅샷이 적용될 수 있습니다. 세 설정을 하나의 스냅샷으로 공유하며 분산 병합/충돌 편집 UI는 없습니다. 한글·긴 프롬프트는 8KB 항목 한도를 넘지 않도록 나누고 해시를 검증해 일부만 받은 내용을 적용하지 않습니다. 총 Chrome Sync 용량은 약 100KB이며 목록이 너무 크거나 한도를 넘으면 로컬 설정을 보존하고 전송 실패를 표시합니다.

검색은 `is:verified`를 항상 붙입니다. 타임라인은 작성자 `verified` 또는 `verified_type` 정보가 인증을 확인해 주는 글만 대기열에 담습니다. 파란딱지·기업·정부 인증을 모두 포함하고 인증 정보가 없거나 비인증이면 제외합니다. 별도 사용자 조회를 추가하지 않습니다. 타임라인 응답에 포함됐다가 제외된 비인증 글도 조회 비용은 발생할 수 있습니다. 이미 받았던 글의 인증 여부가 바뀌는 것을 실시간 추적하지는 않습니다.

## 처음 설치하고 체험하기

고정 ID ZIP을 풀고 `manifest.json`이 있는 `octo-x-assistant-sync` 폴더를 Chrome 116 이상의 개발자 모드에서 로드합니다. 아이콘을 눌러 사이드바를 엽니다. 체험 모드는 가상 글을 사용하며 API 비용이 발생하지 않습니다. API 설정은 아래 절을 참고하세요.

## v1.1.3 통계 표시

사이드바는 오늘의 **수집한 글 / 오늘 본 글 / 예상 비용**, 월간 통계는 이번 달의 **수집한 글 / 본 글 / 예상 비용**을 보여줍니다. 수집한 글은 조건에 맞아 대기열에 추가된 글 수이며, 본 글은 ‘다음 글’로 넘겨 검토 완료 처리한 글 수입니다. 현재 표시만 한 글은 아직 포함하지 않으며 X에서 실제 게시한 댓글 수를 확인하는 기능은 없습니다. 일별 표도 같은 기준을 사용합니다.

이전 버전 X 비용이 검증 대기 상태여도 계산 가능한 금액은 표시하고 **이전 X 제외**를 붙입니다. 이는 전체 비용이 아닌 소계이며, 옆 설명에 제외 사유를 표시합니다. 같은 날짜·범위의 X 콘솔 확인액을 반영하면 해당 날짜의 이전 기록 제외 표시가 해소됩니다.

기록은 `chrome.storage.local`에 저장되어 같은 확장 ID·Chrome 프로필 안에서 업데이트 후에도 유지됩니다. 확장을 제거하거나 새 폴더를 새 확장으로 로드하면 별도 저장소가 될 수 있습니다. v1.3.0부터 댓글 지침·키워드·제외 계정은 Chrome 동기화를 사용합니다. 글·통계·비용의 동기화는 구현되어 있지 않습니다. 같은 Google/X 계정으로 로그인해도 글·통계·비용 기록은 합쳐지지 않습니다. 같은 API 결제 계정의 실제 청구액은 제공사 콘솔에 모이지만, 각 기기의 앱 예상액은 해당 기기의 요청만 집계합니다. 기존 대기 글 백업 내보내기는 전체 데이터 이전/통계 병합 기능이 아닙니다.

## v1.1.2 답글 제외

타임라인은 `exclude=retweets,replies`, 키워드 검색은 `-is:retweet -is:reply`를 적용합니다. 응답의 대화 ID와 답글 참조가 있으면 로컬에서도 다시 제외합니다. 자기 글에 이어 쓴 스레드 후속 답글도 제외하고, 인용 게시물은 포함합니다.

이전 대기 글에는 답글 유형 정보가 없으므로 업데이트 시 기존 대기 글을 백업으로 옮기고 페이지 커서를 초기화합니다. 이미 수정한 초안도 그대로 보존합니다. 설정 → 월간 통계 → **기존 글·초안 백업 내려받기**에서 JSON 파일로 확인할 수 있습니다. 인증·검토 이력·비용 통계는 유지하고 추가 유료 조회는 하지 않습니다. 사이드바의 **더 가져오기**로 새 수집을 시작하세요.

## OpenAI API 설정

1. [OpenAI API 키 관리](https://platform.openai.com/api-keys)에서 기존 API 잔액이 있는 조직·프로젝트를 선택합니다.
2. 키를 발급하거나 기존에 보관한 키를 확장 설정의 **OpenAI API Key**에 입력합니다. 키를 채팅에 보내거나 공유 파일에 넣지 마세요.
3. 제한된 키를 사용하는 경우 Responses API 쓰기 권한과 선택한 모델 이용 권한이 필요합니다.
4. 모델은 기본 `gpt-6-luna`를 유지하고 **설정 저장**을 누릅니다.

키는 이 기기의 확장 저장소에 보관하고 OpenAI 요청에만 사용합니다. 기본 모델은 추론 `none`, 엄격한 JSON Schema 출력, `store: false`로 호출합니다. 웹 검색·X 검색 등 유료 도구를 모델에 연결하지 않습니다.

지원하는 요청 설정:

| 모델 | 추론 설정 |
| --- | --- |
| `gpt-6-luna`, `gpt-6-sol` | none |
| `gpt-6.1-sol`, `gpt-6-astra` | low |
| `gpt-4.1-mini` 등 다른 OpenAI 모델 | 추론 파라미터 생략; 해당 모델 기본 동작 |
| `grok-4.3` | none |
| `grok-4.5`, `grok-4.6`, `grok-4.7` | low |

모델명은 설정에서 변경할 수 있지만, **해당 조직의 접근 권한과 모델별 단가**를 확인해야 합니다. 접근 실패 시 더 비싼 모델로 자동 변경하지 않습니다. ChatGPT 구독과 API 결제는 별도입니다.

## X 개발자 앱 설정

‘개발자 앱’은 별도 설치 프로그램이 아닌, X API와 로그인 권한을 등록하는 X 콘솔의 항목입니다.

1. [X 개발자 사이트](https://developer.x.com/)에서 개발자 계정과 API 앱을 준비합니다. 앱은 Pay Per Use 프로젝트에 연결되어 있어야 하며, 실제 유료 조회에는 X API 잔액이 필요합니다.
2. **User authentication settings**에서 읽기 권한, **Native App 또는 Single Page App(public client)** 유형을 선택합니다. Client Secret을 요구하는 Web App/Bot 유형은 지원하지 않습니다.
3. 확장 설정의 **Callback URL**을 복사해 X 콘솔의 Callback/Redirect URI에 정확히 등록합니다. `https://<확장ID>.chromiumapp.org/oauth2` 형태입니다.
4. Website URL 등 앱 정보는 X 콘솔 요구사항에 맞게 입력합니다. Callback URL과 Website URL은 서로 다른 용도입니다.
5. 해당 앱의 **OAuth 2.0 Client ID**를 확장에 입력합니다. API Key, API Key Secret, 앱 전용 Bearer Token과는 다른 값입니다.
6. **저장하고 X 연결**을 누르고 `tweet.read users.read offline.access`를 승인합니다. 연결 계정이 @JungkwanDean인지 확인하세요.

PKCE S256, state 검증, 만료 시 갱신, 회전된 갱신 토큰의 즉시 저장을 사용합니다. 다른 X 계정으로 연결하면 기존 후보/검토 이력은 초기화되며 설치 단위 비용 통계는 유지됩니다.

## 사용하는 흐름

1. X와 옥토 사이드바를 엽니다.
2. **더 가져오기**를 누릅니다. 타임라인 1페이지와 인증 계정 키워드 검색 1페이지를 읽습니다. 기본은 소스당 25개입니다.
3. 한국어(`lang === ko`)이며 키워드 하나라도 포함된 글을 후보로 보관합니다. 인증 계정만 포함하며 내 글·리포스트·이미 검토한 글·대기 중인 중복은 제외합니다. 답글과 스레드 후속 답글은 제외하고 인용 게시물은 포함합니다.
4. 현재 글만 선택한 AI에 전달해 짧은 요약과 친근한 댓글을 만듭니다. 다른 후보의 댓글은 미리 생성하지 않습니다.
5. **원문 열기**로 현재 탭에서 원문과 맥락을 확인하고 댓글을 수정합니다. 수정은 약 0.5초 후 저장하며 복사·다음 이동 직전에도 저장합니다.
6. **댓글 복사** 후 X에서 직접 붙여넣고 게시합니다.
7. **다음 글**은 검토 완료로 기록하고 다음 글의 초안을 생성합니다. 복사·검토 완료를 실제 게시 완료로 간주하지 않습니다.

일일 앱 수집 제한과 정기 수집은 없습니다. 수집은 ‘더 가져오기’ 클릭에만 발생합니다. 타임라인은 팔로우 계정의 최신순 피드이며, 새로운 계정의 글은 최근 7일 키워드 검색에서 찾습니다. 많은 키워드는 여러 묶음으로 나누어 수집 클릭마다 순환합니다.

다음 페이지 커서를 사용하고, 마지막 페이지 뒤의 다음 클릭은 최신부터 다시 읽습니다. **최신부터 다시**는 커서만 초기화하며, 처리 이력은 보존합니다. 키워드 변경 시에도 커서를 초기화합니다.

게시물 이미지·영상·부모 글 전체를 자동 분석하지 않습니다. 필요한 맥락은 원문에서 확인하세요. 긴 본문은 API가 반환하면 사용합니다. 자동 입력·게시·좋아요·팔로우 또는 팔로우 상태 표시는 없습니다.

## 비용 계산

- **읽은 글:** API 응답의 글 수. 중복·언어/키워드 탈락 글도 포함합니다.
- **새 후보:** 조건을 통과해 대기열에 처음 추가한 글 수.
- **X 비용:** UTC 날짜별 중복 제거 게시물 ID × 게시물 단가 + 단독 사용자 조회 ID × 사용자 단가. 로그인/진단의 성공한 사용자 조회를 반영합니다. 게시물 응답의 `includes.users` 작성자 부가 정보를 별도 사용자 조회로 자동 가산하지 않습니다. 이는 로컬 추정 방식이며 서비스의 모든 과금 예외를 확정하는 규칙은 아닙니다.
- **AI 비용:** 선택한 AI가 반환한 입력·출력·캐시 읽기·캐시 쓰기 토큰 사용량 × 설정 단가 ÷ 1,000,000. 미완료/거절 응답도 반환된 사용량이 있으면 기록합니다.
- 오늘/월간은 **Asia/Seoul** 기준입니다. X 과금 중복 제거는 **UTC 자정**, 즉 한국시간 오전 9시에 창이 바뀝니다.
- 과거 Grok 비용과 신규 OpenAI 비용을 따로 누적하고 AI 합계에 함께 표시합니다. 단가를 변경해도 과거 금액을 다시 계산하지 않습니다.

v1.1.1은 게시물에 딸려온 작성자 정보까지 사용자 단가로 더하던 과다 추정을 수정합니다. 이전 기록에는 요청별 구분이 없어 정확한 소급 계산을 할 수 없습니다. 이전 X 금액은 백업하고 계산 가능한 소계에 **이전 X 제외**를 표시합니다. AI 비용과 글·초안은 유지됩니다.

설정 → 월간 통계에서 최근 요청별 게시물/단독 사용자 건수와 AI 토큰 수를 볼 수 있습니다. 최근 200건을 로컬에 보관하고 화면에 30건을 표시합니다. 이전 금액을 보정하려면 같은 날짜·앱·사용 범위의 콘솔 금액을 확인한 후 **오늘 X 콘솔 확인액 반영**을 선택적으로 사용하세요. 이 값은 수동 기준액이며 이후 신규 조회 추정치를 더합니다. UTC와 한국시간의 기간 차이 및 콘솔 반올림 오차를 확인해야 합니다. 과거 다른 날짜의 검증 대기 기록은 그대로 남습니다.

## X 연결 진단과 오류

X 계정 조회가 실패하면 설정의 **연결 진단**을 누르세요. 저장된 토큰으로 `/2/users/me`와 `/2/users/by/username/JungkwanDean`을 한 번씩 비교합니다. 오래된 토큰의 권한 정보는 필요하면 한 번 조용히 갱신합니다. 로그인 창은 열지 않습니다.

진단은 사용자 정보 최대 2건의 읽기 비용이 발생할 수 있습니다(기본 단가 기준 최대 $0.02). API 경로·HTTP 상태·허용 목록의 오류 식별자·승인 scope·토큰 종류만 표시합니다. 키/토큰 원문과 서버의 자유 형식 설명은 포함하지 않습니다. **진단 결과 복사**로 결과만 전달할 수 있습니다.

| 증상 | 확인할 것 |
| --- | --- |
| X 200, credits-depleted 402 | 인증 성공. X API 잔액 확인 |
| X 갱신 실패/401 | 앱·계정·권한 확인, 연결 진단 또는 재연결 |
| OpenAI invalid_api_key | OpenAI 필드에 해당 제공사의 키가 입력됐는지 확인 |
| OpenAI insufficient_quota | 기존 잔액이 있는 조직·프로젝트인지, API 한도/결제 확인 |
| OpenAI model_not_found | 모델 ID, 프로젝트 모델 접근 권한 확인 |
| OpenAI 403 | 키의 Responses 쓰기 권한과 모델 이용 권한 확인 |
| 429 | 요청 한도 대기 후 직접 재시도. 생성 요청은 자동 재시도하지 않음 |
| 후보가 없음 | 키워드·언어 필터·팔로우 피드·검색 범위 확인 |
| 요약/댓글 실패 | 수집된 글은 보존됨. 설정 확인 후 다시 생성 |
| 클립보드 오류 | textarea에서 직접 선택·복사 또는 Chrome 권한 확인 |

## 저장·전송·권한

- 로컬 저장: 설정, 제공사별 키, X 토큰, 대기 글, 수정 초안, 검토 ID, 통계. `chrome.storage.local`만 사용하며 trusted extension contexts로 제한합니다. 별도 서버/Content script는 없습니다. 댓글 지침·키워드·제외 계정만 Chrome 동기화 저장소에도 전송합니다. 로컬 저장소는 암호화 금고가 아닙니다.
- X 전송: OAuth 코드·PKCE·토큰, 타임라인/검색 요청과 키워드.
- 선택한 AI에만 전송: 해당 제공사의 키, 현재 글의 작성자 이름·본문, 댓글 작성 지침. Responses API에 `store: false`를 지정합니다. 각 사업자의 데이터 처리 정책도 적용됩니다.
- 권한: identity(OAuth), sidePanel, storage, unlimitedStorage(일일 제한 없는 후보·처리 이력), clipboardWrite(사용자 클릭 복사).
- 접근 호스트: api.x.com, api.openai.com, api.x.ai. AI 요청은 선택한 제공사로만 보냅니다.
- 연결 해제는 로컬 X 토큰을 삭제합니다. 원격 권한 철회는 X의 연결된 앱에서 처리하세요. 제공사 키를 지우려면 해당 제공사 선택 후 키를 비우고 저장합니다. 필요하면 제공사 콘솔에서도 폐기하세요.
- 확장 삭제 시 로컬 데이터가 삭제됩니다.

## 파일·검증

`manifest.json`, `background.js`, `core.js`, `sidepanel.html/js/css`, `options.html/js/css`, `ui.js`, `sync.js`, `backup.js`가 실행 파일입니다. `tests/*.test.js`는 네트워크 없는 Node 테스트이고, `tests/ui-smoke.mjs`는 임시 Chromium 프로필에서 실행하는 Playwright UI 검사입니다.

```sh
cd octo-x-assistant
npm test
# Playwright와 확장 로드 가능한 Chromium이 준비된 경우
node tests/ui-smoke.mjs
```

실제 OpenAI 키가 제공되지 않아 유료 GPT 호출과 계정의 모델 접근은 검증하지 않았습니다. 테스트에서는 모의 응답을 사용합니다. 사용자 Chrome 계정/프로필이나 실제 API 비용을 사용하지 않습니다. 자세한 검증 기록은 `VERIFICATION.md`를 참고하세요.
